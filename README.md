# ✍️ أداة كتابة محتوى SEO بالعربية

أداة متقدمة لكتابة محتوى احترافي متوافق مع محركات البحث باللغة العربية باستخدام الذكاء الاصطناعي.

## 🚀 المميزات
- ✅ كتابة محتوى عربي احترافي متوافق مع SEO
- ✅ توليد هيكل المقال تلقائياً
- ✅ دعم نبرات كتابة متعددة (احترافي، ودي، تسويقي)
- ✅ استهداف أسواق عربية مختلفة (سعودي، مصري، إماراتي، إلخ)
- ✅ واجهة سهلة الاستخدام تدعم اللغة العربية (RTL)

## 🔧 كيفية الاستخدام
1. أدخل الكلمة المفتاحية الرئيسية.
2. اختر نبرة الكتابة والجمهور المستهدف.
3. اضغط على "توليد الهيكل" أو "توليد المقال الكامل".
4. انسخ النتيجة واستخدمها في مدونتك أو موقعك.

## 🔒 ملاحظة أمنية
هذا المشروع يستخدم مفتاح API خاص بـ OpenAI. يجب حفظ المفتاح في إعدادات الاستضافة (مثل Streamlit Secrets) وعدم مشاركته أبداً.
